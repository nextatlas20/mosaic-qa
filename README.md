# MosaicQA

A multilingual benchmark for document-grounded question answering.

Release status: public release (v0.4.0)

The benchmark data is distributed under CC BY 4.0; the build scripts are MIT licensed
and live in `build_dataset.py`. Nine of the fourteen languages are final in this
release; the remaining five will follow in v0.5.

```
python build_dataset.py --languages en,fr,sw,hi --out data/
```
